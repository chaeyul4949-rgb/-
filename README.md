# 발롱 드림 ⚽

벤치에서 시작해 발롱도르까지. 17살 유스 선수를 키우는 축구 커리어 시뮬레이션 웹 게임입니다.
빌드 없이 `index.html`만 열면 바로 실행돼요.

## 파일 구조
- `js/data.js` — 포지션, 능력치 가중치, 국가, 리그·클럽 전력 (밸런스 숫자는 여기서 수정)
- `js/engine.js` — 게임 로직 (경기, 성장, 시즌, 시상, 이적, 이벤트)
- `js/app.js` — 화면
- `css/style.css` — 스타일

## 핵심 시스템
- 선수 생성: 포지션별 후보 3명 (오버롤 45, 보이는 능력치 합 240), 집중 육성 1~2개
- 숨겨진 잠재력 등급(C~SS)과 성장 특성(조기 완성형/표준형/대기만성형)
- 성장: 나이 + 출전 시간 + 평점 + 부상, 잠재력이 상한. 성인 무대 출전이 부족하면 잠재력이 깎임
- 시즌: 리그 + 국내 컵 + 대륙 대회(UCL, ACLE), 승강제, 랜덤 이벤트
- 시즌 종료: 득점왕/도움왕/MVP/영플레이어/베스트11, 국가대표·월드컵·대륙컵, 발롱도르
- 은퇴 후 명예의 전당 (발롱도르 → 최고 OVR → 개인상 → 공격포인트 순)
